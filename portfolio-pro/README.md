# Portfolio Pro - Modern Professional Portfolio

A premium, professional portfolio built with cutting-edge web technologies.

## 🚀 Tech Stack

- **React 19** - Latest React with improved performance
- **TypeScript** - Full type safety across the project
- **Tailwind CSS 4** - Next-generation utility CSS framework
- **Framer Motion** - Smooth, professional animations
- **Vite 5** - Lightning-fast build tool
- **Lucide Icons** - Beautiful, consistent icons

## ✨ Features

- ✅ Responsive design for all devices
- ✅ Smooth scroll animations with Framer Motion
- ✅ Accessibility-first approach
- ✅ Dark mode optimized
- ✅ Fast performance (Vite optimized)
- ✅ Mobile-friendly navigation
- ✅ SEO ready
- ✅ TypeScript for type safety

## 📋 Sections

- **Navigation** - Sticky header with smooth scrolling
- **Hero** - Engaging introduction with CTA
- **About** - Personal introduction with skill grid
- **Experience** - Professional background timeline
- **Projects** - Featured work showcase
- **Skills** - Expertise categories
- **Contact** - Call-to-action and social links
- **Footer** - Copyright and credits

## 🛠️ Setup & Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linting
npm run lint
```

## 📁 Project Structure

```
src/
├── components/      # React components
├── hooks/          # Custom React hooks
├── index.css       # Global styles
├── App.tsx         # Main app component
└── main.tsx        # Entry point
```

## 🎨 Customization

- **Colors**: Edit `tailwind.config.ts` to customize the color scheme
- **Content**: Update component content directly in component files
- **Animations**: Adjust Framer Motion variants in components
- **Fonts**: Change font imports in `index.html`

## 📝 Notes

- Replace placeholder content with your actual information
- Update social media links in components
- Add your project details in the Projects section
- Customize colors and styling in Tailwind config
- Don't forget to update the email link in the Contact section
